 LCA(LOWEST COMMON ANCESTOR)
 LCA usually refers to Lowest Common Ancestor in computer science, especially in tree data structures. It’s a classic problem: given two nodes in a tree, the LCA is the deepest node that is an ancestor of both.

Example
Suppose you have a binary tree:

Code
        1
       / \
      2   3
     / \
    4   5
LCA(4, 5) = 2

LCA(4, 3) = 1
